Casino Multithreading Project

Work Detail Page

Context / Problem

This project focuses on a unique casino game that focuses on concepts like OOP and multithreading. The game is a simple slot machine game where users can bet on different symbols and win or lose based on the outcome of the spin. The main problem that this project addresses is how to implement a casino game that is both fun and engaging while also incorporating important programming concepts like multithreading and OOP.

Tools / Technologies

  • Java
  • JavaFX
  • Multithreading Concepts
  • OOP concepts

Reflection (What I’d Improve Next)

If I were to improve this project, I would focus on having a better UI design and more games for users to play. I would also add a multiplayer feature so that users can go against each other.
